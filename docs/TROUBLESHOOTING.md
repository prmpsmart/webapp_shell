# Troubleshooting

| What you see                                                               | Why                                                                      | What to do                                                                                                                             |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `the compiled frontend is missing: <path>`                                 | `frontend/dist/index.html` is not where `BackendSpec.frontend_dist` says | Build the frontend, or fix `source_root` / `frontend_dist`. A frozen program must carry the folder as data.                            |
| `the backend did not answer /api/health within 20 seconds`                 | The process is running but its health path never answered 200            | Run `python -m <module> --port 8765 --token x --frontend <dist>` by hand and read its output. The health path must not need the token. |
| `the backend stopped while starting (exit code N)`                         | The process ended before it answered                                     | The same: run it by hand; the exit code and its own output say why (an import error, a port in use).                                   |
| `The backend stopped several times in a row…`                              | The backend died more than 3 times within 120 s                          | The same: run it by hand. Its output is not shown by the shell.                                                                        |
| The page loads but every API call is 401                                   | The token did not become a cookie                                        | The backend must turn the `token_query` value of the first request into the `token_cookie` cookie (`TokenGuard` does).                 |
| A socket is closed at once with 4401                                       | No valid token, or a foreign origin                                      | Use `WebSocketGuard.accept`; the page connects from the same address it was served from.                                               |
| `pickFile` rejected: `"start" must be text`                                | A native argument has the wrong type                                     | The messages name the argument; nothing is converted silently.                                                                         |
| Windows: the window has no icon                                            | `.ico` was not given                                                     | Set `AppIdentity.icon_ico`; Windows reads only `.ico`.                                                                                 |
| Windows: the window does not open                                          | WebView2 runtime is missing (pywebview uses it)                          | Install the Microsoft WebView2 runtime (already on Windows 11).                                                                        |
| Windowed program fails at start with `'NoneType'` errors about streams     | No console, `sys.stdout` is `None`                                       | `run()` already handles it; if you start the backend yourself, call `ensure_standard_streams()` first.                                 |
| The pywebview API object breaks on Windows with thread or recursion errors | pywebview walks every public attribute of the API object                 | Keep what you give pywebview private; the library's bridge already does.                                                               |
| Qt: no window in a test                                                    | No display                                                               | `QT_QPA_PLATFORM=offscreen` with `--smoke`.                                                                                            |
