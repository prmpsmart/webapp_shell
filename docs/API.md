# API listing

Generated by `python tools/api_listing.py` from the source; do not edit by hand (a test fails when it is out of date).

This is the whole public API: what a project imports (`webapp_shell`, `webapp_shell.contract`) and what it can use to
tune the shell (`webapp_shell.contract.guard`, `standard_functions`, `build_parser`, `Installation`, `ShellMessages`).
Nothing else is promised: a module or name that is not listed here can change in any release, even though it can be
imported.

Public names: 32.

## `webapp_shell.backend`

How a project's backend is started: a Python module run as `python -m <module>` (or, in a frozen program, by the program running itself).

- `class CliFlag` — A command-line switch the project adds to its program (`--sandbox`). When given, the backend gets `passes`.
  - `name: str`
  - `help: str`
  - `passes: tuple[str, ...]`
- `class BackendSpec`
  - `module: str`
  - `wire: WireProtocol`
  - `frontend_dist: Path`
  - `frontend_argument: str`
  - `port_argument: str`
  - `preferences_argument: str | None`
  - `arguments: tuple[str, ...]`
  - `source_only_arguments: tuple[str, ...]`
  - `flags: tuple[CliFlag, ...]`
  - `package_dirs: tuple[Path, ...]`

## `webapp_shell.contract.guard`

Access control for a Starlette or FastAPI backend: the launch token, from a header or a cookie.

- `class GuardResponses` — What a refused request gets back. A project with its own error format replaces them.
  - `unauthorized: dict[str, str]`
  - `foreign_origin: dict[str, str]`
- `class TokenGuard(BaseHTTPMiddleware)` — Protects the API with the launch token.
  - `def __init__(self, app: ASGIApp, validator: TokenValidator, wire: WireProtocol, origins: OriginPolicy | None=None, responses: GuardResponses | None=None)`
  - `async def dispatch(self, request: Request, call_next: RequestResponseEndpoint) -> Response`
- `class WebSocketGuard` — The same rules for a socket as `TokenGuard` has for a request: the token (header, cookie or query string) and the origin. A refused socket is closed with `wire.ws_close_unauthorized` before it is accepted.
  - `def __init__(self, validator: TokenValidator, wire: WireProtocol, origins: OriginPolicy | None=None)`
  - `def allows(self, socket: WebSocket) -> bool`
  - `async def accept(self, socket: WebSocket) -> bool`

## `webapp_shell.contract.launch`

The command line the shell starts a backend with, read by the backend: the port, the compiled frontend, the preferences file and the token. The argument names come from the same `BackendSpec` the shell builds the command from, so the two cannot drift.

- `class LaunchArguments`
  - `port: int`
  - `token: str`
  - `frontend: Path | None`
  - `preferences_file: Path | None`
  - `host: str`
- `def add_launch_arguments(parser: argparse.ArgumentParser, backend: BackendSpec) -> None` — Adds the standard arguments to a backend's parser. Read them back with `LaunchArguments.of(args, ...)`.
- `def read_launch_arguments(parser: argparse.ArgumentParser, args: argparse.Namespace, wire: WireProtocol) -> LaunchArguments` — Checks the token is there (the parser reports the error) and gathers the standard arguments.

## `webapp_shell.contract.tokens`

Decides whether a candidate is the launch token, and whether a request comes from the app's own page. No HTTP framework code here.

- `class TokenValidator`
  - `def __init__(self, token: str, wire: WireProtocol)`
  - `property token(self) -> str`
  - `def is_valid(self, candidate: str | None) -> bool`
  - `def is_valid_connection(self, headers: Mapping[str, str], cookies: Mapping[str, str], query: Mapping[str, str]) -> bool`
- `class OriginPolicy` — A browser tells which page made a request in `Origin`. Cookies are shared by every port of a host, so another program's page on 127.0.0.1 would otherwise be allowed to call this one: only the app's own page is.
  - `def allows(self, origin: str | None, host: str | None) -> bool`
