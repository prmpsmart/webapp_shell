# API listing

Generated by `python tools/api_listing.py` from the source; do not edit by hand (a test fails when it is out of date).
Every public name (no leading underscore) of every module, with its signature. **Exported** means the name is in the
`__all__` of `webapp_shell` or of `webapp_shell.contract`, the two places a project imports from. The rest is public
only because it has no underscore: the owner decides which of those stay public and which are renamed with `_`.

## `webapp_shell.native.zoom`

Page zoom (Cmd/Ctrl +, -, 0). The page decides the factor and keeps it as an app preference; each shell only applies it to its web view. Qt has `setZoomFactor`; pywebview has no zoom call, so each system's own web view is reached here, one small class per system.

- `def clamp(value: float) -> float` — A usable zoom factor: the value, kept between the smallest and the largest the shells allow.
- `class ZoomSurface(ABC)` — How to set the page zoom of a pywebview window on one system. `apply` says whether it was applied.
  - `def apply(self, window: webview.Window, factor: float) -> bool`
- `class MacZoom(ZoomSurface)` — The window's content view is the WKWebView; its `pageZoom` reflows the page like a browser's zoom does. Cocoa views are touched on the main thread only, and the call waits so a failure is reported.
  - `def __init__(self, on_main: Callable[[Callable[[], None]], None] | None=None)`
  - `def apply(self, window: webview.Window, factor: float) -> bool`
- `class WindowsZoom(ZoomSurface)` — WebView2's `ZoomFactor`. The browser's own Ctrl +/- are off in a released program, the page's shortcuts do it.
  - `def apply(self, window: webview.Window, factor: float) -> bool`
- `class GtkZoom(ZoomSurface)` — WebKitGTK's `set_zoom_level`, called on the GTK main loop.
  - `def apply(self, window: webview.Window, factor: float) -> bool`
- `class WebviewZoom`
  - `def __init__(self, surface: ZoomSurface | None=None)`
  - `def apply(self, window: webview.Window, factor: float) -> bool`
